# 案件情報抽出の指示

Guided Links の機能があるAIの場合は Guided Links を使わずに実行してください。

## 指示1

この指示の後ろに付いている「案件情報」から、次の必須条件を満たした上で優先条件に適合する上位3件を抽出してください。

### 必須条件

- 単価（金額）が明示されていること。
- 勤務地、またはリモート可・在宅可であることが明記されていること。

### 優先する条件

1. 「地方可」「地方歓迎」「フルリモート」が明記されていること。
2. 上記の条件を満たす中で、単価（契約額）が比較的高いこと。
3. 抽出する3件同士で、職種や技術分野（例: インフラ・開発・PMO等）が重複しないように分散させること。

## 指示2

抽出した3件の案件情報をそれぞれ下記のテンプレートに従って Markdown 文書を作成してください。
出力の際は、そのままコピー＆ペーストして使用できるよう、各案件の Markdown を markdown コードブロックで囲んで出力してください。
さらに各 Markdown の直後に、対応する案件の原文を添付してください。

### 原文出力ルール

- 原文は text コードブロックで囲むこと
- 原文は案件情報から該当案件のブロック全体を転載すること
- code: から次の ----- までを完全に転載すること
- 入力文の改行・空白・記号を維持すること
- 要約・省略・整形・言い換えを行わないこと
- 不要な説明や補足を追加しないこと
- 原文は Markdown 生成結果の検証用途である
- 原文と入力文が一致する状態で出力すること

## テンプレート記入項目についての補足説明

### date

- 対応する案件情報の原文に記載されている `date:` の値（例: `2026/10/28`）をそのまま使用し、指定のフォーマット（ISO 8601形式：`yyyy-mm-ddThh:mm:ss`）に変換して設定すること。
- 本日の日付や実行時の現在日時は絶対に使用しないこと。
- hh は 18 固定とします。
- mm は、1件目の案件が 01、2件目が 02、3件目が 03 です。

### title の 'yy/m

- 開始月を記載します。
- 例:
  - '26/10
  - '26/9(即日)
  - '26/12 or '27/1

### title の 【場所】 および 表の「場所」

以下の優先順で判定して設定してください。

- 名称の正規化:
  - 駅名や細かい地名が含まれる場合は自治体名に置き換える
  - 例:
    - 大宮 → さいたま市
    - 小川町 → 千代田区
    - 曙橋、新宿 → 新宿区
    - 茅場町、門前仲町 → 中央区
    - 大崎 → 品川区
    - 目黒駅 → 品川区
    - 品川駅 → 港区
- リモートの位置判定:
  - 「在宅〇割」「リモート併用」等の記載で、週3日以上リモートまたは在宅メインの場合は「リモート/自治体名」
  - 週2日以下のリモートや「リモート併用」で出社メインの場合は「自治体名/リモート」
  - 常駐の場合は自治体名のみ
- 地方可の付記:
  - 「地方可」「地方歓迎」が明記されている場合のみ記載する
  - 例:
    - フルリモート地方可
    - リモート/江東区 地方可

### title の 言語・職種など

- プログラミング言語
- フレームワーク
- 製品名
- クラウドサービス名
- 職種

が明示されている場合のみ記載してください。

重複除外ルール:

- タイトル本体（コロン「：」の後ろの文面）に含まれている単語や役割・作業内容（例: 「保守開発」「構築」「運用」「PMO」等）は、「言語・職種など」側に重複して記載しない（例: タイトル本体に「〜の保守開発支援」とある場合は「保守開発」を除外して「Java：受注・製造管理システムの保守開発支援」とする）
- 言語とフレームワークが両方ある場合はフレームワークを優先する
- Java + SpringBoot の場合は SpringBoot のみ記載する
- 「AXエンジニア」や「PMO」のような設計開発以外の職種等がタイトルに含まれている場合、プログラム言語やフレームワークなどの設計開発に要求されるスキルの記載は不要とする。（例：「AXエンジニア」の案件でPython等が必須であってもタイトルには含めない）

### title の タイトル

- 元の案件名から「某」と「募集」を除外してください。

### 契約額

- 「スキル見合い」「応相談」は除外する
- 金額部分のみ記載する

例:

- 65万円
- ～60万円
- 60～80万円
- 95万円

### 期間

例:

- '26年10月〜
- '26年10月 or 11月〜
- '26年10月(即日)〜
- '26年10月〜'27年3月(延長あり)

### 必要スキル

- 必須スキルのみ記載する
- 尚可スキルは記載しない
- 文面は原文のまま極力変更しない
- 「一人称で」など不自然な表現のみ適切に補正してよい
- 親項目（例: 「以下いずれかの経験」など）の下位項目は、ハイフンをネスト（インデント）させたリスト形式で記載する

### 業務内容

- 原文をできるだけ尊重して記載する
- 文章と箇条書きの併用可
- 内容を追加しない
- 内容を推測しない
- 箇条書きではない地の文章（説明文）は途中で改行せず1つの段落にまとめ、文末には必ず「。」を付ける
